# Cloak

English · [简体中文](README.zh-CN.md)

A personal, native rule-based proxy client for Apple platforms (macOS / iOS / tvOS), rebuilt from [TokenPLS/Hako-Client](https://github.com/TokenPLS/Hako-Client) — originally "Clash for Apple Platforms" — and renamed **Cloak**.

> **Fork notice** · This repository is a **fork** of [TokenPLS/Hako-Client](https://github.com/TokenPLS/Hako-Client), maintained for personal use. The product is renamed to **Cloak** and built/signed with the maintainer's own Apple Developer account. On-disk profile format and URL schemes (`clash`, `clashmeta`, `flclash`, `hako`) are left compatible with upstream, so existing subscriptions and configuration imports keep working. Upstream App Store / official-website material has been removed from this fork.

## Components

The client runs on the [Hako kernel](https://github.com/TokenPLS/Hako) with bridge code from [Hako-Adapter](https://github.com/TokenPLS/Hako-Adapter). Both live in separate repositories; the source revisions used here are pinned in [`Dependencies.lock.json`](Dependencies.lock.json).

| Directory | Contents |
| --- | --- |
| `apple/HakoClient` | Platform applications, extensions and XcodeGen project specification |
| `apple/HakoClientKit` | Shared configuration and profile models |
| `apple/HakoClientUI` | Shared interface components |
| `apple/HakoMacClient` | macOS components |

## Build from source (macOS)

### Requirements

- macOS with Xcode 26.6 and the iOS, macOS and tvOS SDKs.
- XcodeGen and Git available on your command path.
- Go with automatic toolchain selection enabled, or the Go 1.26.6 toolchain selected by the pinned kernel's binding module.
- Python 3 with PyYAML.

### Prepare the project

```sh
git clone git@github.com:wflixu/Cloak.git
cd Cloak
python3 -m venv .build/python-env
source .build/python-env/bin/activate
python3 -m pip install PyYAML
python3 scripts/bootstrap.py
python3 scripts/configure.py
```

The first bootstrap fetches the pinned kernel and Adapter sources, installs the pinned gomobile tools and builds the five-slice SDK. It requires network access and can take several minutes. The configure step generates the Xcode project. (A populated `.build/` cache is kept out of git; it is regenerated by `bootstrap.py`.)

Open `apple/HakoClient/HakoClient.xcodeproj` and choose a scheme:

| Platform | Scheme |
| --- | --- |
| Mac | `HakoMac` |
| iPhone / iPad | `HakoClient` |
| Apple TV | `HakoTV` |

For an unsigned iOS Simulator build:

```sh
xcodebuild -project apple/HakoClient/HakoClient.xcodeproj \
  -scheme HakoClient -configuration Release \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

### Sign your own build

This repository is preconfigured for the maintainer's own bundle identifier family (`cn.wflixu.cloak`) and Apple Developer Team. To build under your own identity:

```sh
python3 scripts/configure.py --bundle-base org.yourname.cloak --team YOURTEAMID
```

Then configure signing and capabilities for the app and its extensions in Xcode (Network Extensions, App Groups, and any iCloud capabilities you use). Certificates and provisioning profiles are not included; an unsigned build only checks compilation.
